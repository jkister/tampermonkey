# tampermonkey

A collection of my [Tampermonkey](https://www.tampermonkey.net/) userscripts.

## Scripts

| Script | Description |
| --- | --- |
| [IPAddrInfo](src/IPAddrInfo.user.js) | Highlight an IPv4/IPv6 address to see its IP assignment / Whois information in a toast popup. |

## Installation

1. Install the Tampermonkey extension for your browser.
2. Click a script's `.user.js` link above, then choose **Raw** — Tampermonkey will offer to install it.
